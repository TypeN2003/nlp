# ระบบวิเคราะห์โพสต์เตือนภัย / ข่าวอุบัติเหตุ (Disaster & Accident Alert Analyzer)

รหัสนักศึกษา: 6706022511014
ชื่อ-สกุล: วิทวัส แก้ววิเศษ

Web Application (Streamlit) สำหรับประมวลผลข้อความโพสต์เตือนภัย/ข่าวอุบัติเหตุ ทั้งภาษาไทยและอังกฤษ
โดยสกัด **สถานที่เกิดเหตุ, วันเวลา, จำนวนผู้บาดเจ็บ/เสียชีวิต และหน่วยงานที่เข้าช่วยเหลือ** ออกมาให้อัตโนมัติ

## แนวคิดของ Domain

โพสต์เตือนภัย/ข่าวอุบัติเหตุที่แชร์ในโซเชียลมีเดียหรือสำนักข่าว มักมีข้อมูลสำคัญปะปนกับ noise
(ลิงก์ข่าว, แฮชแท็ก, การกล่าวถึงบัญชี) ระบบนี้ช่วยกรอง noise ออก และดึงข้อมูลที่เป็นประโยชน์ต่อการ
ประสานงานช่วยเหลือ/ติดตามสถานการณ์ ได้แก่ สถานที่, เวลาเกิดเหตุ, ความรุนแรง (จำนวนผู้บาดเจ็บ/เสียชีวิต)
และหน่วยงานที่เกี่ยวข้อง พร้อมจัดหมวดหมู่ประเภทเหตุการณ์ (ไฟไหม้ / น้ำท่วม / อุบัติเหตุจราจร / แผ่นดินไหว / ระเบิด / อาชญากรรม)

## เทคนิค NLP ที่ใช้

| เทคนิค | การนำไปใช้ |
|---|---|
| Regex & Cleansing | ลบ URL, @mention, #hashtag, emoji ออกจากข้อความ; สกัดเบอร์โทร/เบอร์สายด่วนฉุกเฉิน (1669, 191, 199 ฯลฯ) แยกออกมาต่างหาก |
| Tokenization & Normalization | ตัดคำภาษาไทยด้วย PyThaiNLP (engine `newmm`), ลบ stopwords, ปรับคำพิมพ์ซ้ำ/คำลากเสียง (เช่น "มากกกก" -> "มากก") |
| Topic Identification | จัดหมวดหมู่ประเภทเหตุการณ์ด้วยการให้คะแนนจาก keyword dictionary (ไฟไหม้, น้ำท่วม, อุบัติเหตุจราจร, ตึกถล่ม/แผ่นดินไหว, ระเบิด, อาชญากรรม) |
| NER (Rule/Dictionary-based) | สกัด**สถานที่** (รายชื่อ 77 จังหวัด + pattern ถนน/ซอย/แยก/อำเภอ/ตำบล), **วันเวลา** (regex เวลา/วันที่ + คำบอกเวลาสัมพัทธ์), **ผู้บาดเจ็บ/เสียชีวิต** (regex จับตัวเลขคู่กับคำสำคัญ), **หน่วยงานช่วยเหลือ** (dictionary หน่วยกู้ภัย/มูลนิธิ/ตำรวจ/โรงพยาบาล ฯลฯ) |

## โครงสร้างไฟล์

```
app.py            # Streamlit UI หลัก
nlp_pipeline.py   # โมดูลประมวลผล NLP ทั้งหมด (clean, tokenize, topic, NER)
requirements.txt  # ไลบรารีที่ต้องใช้
sample_data.csv   # ข้อมูลทดสอบ (15 โพสต์ ไทย/อังกฤษ)
```

## วิธีใช้งาน

### รันบนเครื่อง (local)

```bash
pip install -r requirements.txt
streamlit run app.py
```

### วิธีใช้งานหน้าเว็บ

1. เลือกโหมด **วิเคราะห์ข้อความเดี่ยว** แล้ววางข้อความ (หรือกดปุ่ม "ใช้ข้อความตัวอย่าง") แล้วกด "วิเคราะห์"
2. หรือเลือกโหมด **วิเคราะห์แบบ Batch (CSV)** แล้วอัปโหลดไฟล์ที่มีคอลัมน์ `text` (ดูตัวอย่างที่ `sample_data.csv`)
   เพื่อวิเคราะห์หลายข้อความพร้อมกัน และดาวน์โหลดผลลัพธ์เป็น CSV
